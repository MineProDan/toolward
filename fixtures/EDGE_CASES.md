# Fixture edge cases

`fixtures/community.json` is generated by `scripts/make_fixtures.py` (seed 42). All data is synthetic.
These cases are placed on purpose, and `tests/test_fixtures.py` checks that each one exists.

**Time reference.** `config.reference_now` is `2026-10-01T00:00:00Z`, and every relative window is measured back from it. "Week" means the 168 hours before `reference_now` (from `2026-09-24T00:00:00Z`), and "month" means 30 days. Hourly stats start at `config.stats_started_at` = `2026-08-17T00:00:00Z`.

**Acting identity.** `config.acting_member_id` = `mem_0012` (Moderator). The bot is `mem_0031`, and the owner is `mem_0001`.
