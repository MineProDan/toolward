# Tool-count experiment

Generated by `uv run python scripts/make_tool_count_report.py`. Don't edit by hand. All data is synthetic.

**Question:** does a small model get worse at the same tasks when it is shown more tools? Every one of the 26 cases can be solved with the 3 core tools (`lookup_member`, `get_leaderboard`, `get_automod_log`) and mentions no other tool, so the extra tools in the 5 and 7 tool runs are never needed. The system prompt is the same in all three. Case selection: `toolward.evals.experiments.tool_count_cases`.

Settings: `qwen3:8b` (`500a1f067a9f`), think=False, temperature 0.0, seed 42, num_ctx 8192, num_predict 4096, prompt V1, descriptions V4, confirm mode v1, k=1.
